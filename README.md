# MindsDB

MindsDB is an open-source AI layer that simplifies the process of building and deploying AI models.

## Installation

To get started with MindsDB, follow these instructions:

1. Clone the repository:
   ```bash
   git clone https://github.com/mindsdb/mindsdb.git
   ```
2. Change to the MindsDB directory:
   ```bash
   cd mindsdb
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Once installed, you can start using MindsDB easily. Here’s a simple example:

```python
import mindsdb

# Your code here
```
