## การเรียกใช้เอกสารในเครื่อง

ขั้นแรก ติดตั้ง `mintlify`:

```
npm i -g mintlify
```

จากนั้น เริ่มเซิร์ฟเวอร์:

```
mintlify dev
```

เว็บไซต์เอกสารจะพร้อมใช้งานที่ `http://127.0.0.1:3000`
